MellowConvert for Mac Support

Help with importing files, choosing an output folder, conversion, Pro purchases, and restoring purchases.

Contact

Email: nicechann@gmail.com

Please include your Mac model, macOS version, MellowConvert version, the steps that caused the issue, and the input/output format you selected. Do not send private images unless they are necessary and you are comfortable sharing them.

Adding files and folders

Use Add Files, Add Folder, or drag and drop. Recursive subfolder scanning is a Pro feature.

Output formats

The current Mac version can export converted results as JPEG, PNG, HEIC, or PDF.

Output folder access

Choose a folder when prompted. If access no longer works, select the output folder again in the app.

External drives

Reconnect and unlock the drive before opening a previous result. If needed, choose the output folder again.

Pro purchase

Open Settings or the Pro screen to purchase. Use Restore Purchases if you already bought Pro with the same Apple Account.

Multi-frame files

For files containing multiple frames or pages, the current version converts the first item only.
