개인정보 처리방침

MellowLogic · 시행일: 2026년 11월 6일

수사 기록은 기기에 남습니다. 플레이 기록 공유는 사용자가 직접 선택합니다.

1. 운영자와 적용 범위

Nicechann Studio는 MellowLogic 앱과 이 안내 웹사이트를 제공합니다. 개인정보 관련 문의는 nicechann@gmail.com으로 보내 주세요.

2. 앱의 데이터 수집 및 추적

MellowLogic은 계정 가입을 요구하지 않으며, 개발자가 운영하는 서버로 개인정보나 플레이 기록을 자동 전송하지 않습니다. 앱에는 광고 또는 이용자 추적을 위한 SDK가 포함되어 있지 않습니다.

3. 기기에 저장하는 정보

앱은 퍼즐 진행, 인물 배치와 제외 표시, 완료 기록, 플레이 테스트 기록, 놀이 방법 확인 여부와 진동 설정을 기기에 저장합니다. 플레이 기록에는 퍼즐·시도 식별자, 플레이 일시와 활성 시간, 조작·되돌리기·초기화·오답 횟수, 힌트 사용 및 해결 여부 등이 포함될 수 있습니다. 이는 게임 진행과 플레이 경험 확인을 위해 사용되며 자동 업로드되지 않습니다.

4. 사용자가 선택하는 기록 내보내기

설정에서 플레이 테스트 기록 내보내기를 선택하고 iOS 공유 화면에서 대상을 지정하면 해당 파일이 선택한 서비스나 수신자에게 전달됩니다. 파일에는 플레이 기록 외에 앱·콘텐츠 버전, OS 버전, 기기 모델 코드, 언어, 글자 크기, VoiceOver 사용 여부와 내보낸 시각이 포함될 수 있습니다. 기기 이름이나 광고 식별자는 포함하지 않습니다. 공유 대상의 데이터 처리는 해당 서비스의 정책을 따릅니다. 앱의 임시 내보내기 파일은 공유 화면을 닫거나 기록을 지울 때 정리되지만, 외부에 저장된 사본은 남을 수 있습니다.

5. 보관 및 삭제

설정의 진행 초기화는 퍼즐 진행과 완료 기록을 삭제하며 플레이 테스트 기록은 남깁니다. 기록 지우기를 별도로 실행하면 기기에 저장된 플레이 테스트 기록을 삭제할 수 있습니다. 앱 삭제 시 앱의 로컬 데이터도 일반적으로 삭제됩니다. 기기 백업과 이미 내보낸 파일은 iOS 또는 해당 저장 서비스에서 별도로 관리·삭제해 주세요.

6. 문의 정보

이메일로 문의하시면 이메일 주소, 메시지, 자발적으로 첨부한 스크린샷이나 기록을 문의 응대와 문제 해결을 위해 처리합니다. 민감한 정보는 보내지 마세요. 문의 자료는 응대에 필요한 동안만 보관하며, 삭제 요청은 같은 이메일로 보내실 수 있습니다. 이메일 서비스 제공자는 메시지를 처리할 수 있습니다.

7. 웹사이트와 외부 서비스

이 웹사이트에는 별도의 분석 도구나 광고 추적 코드를 설치하지 않았습니다. GitHub Pages에서 호스팅하므로 GitHub는 서비스 제공과 보안을 위해 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보 보호정책을 확인하세요. iOS의 백업·진단 등 Apple 서비스의 데이터 처리는 Apple 개인정보 보호정책을 따릅니다.

8. 아동의 개인정보

앱은 이용자의 나이나 연락처를 요청하지 않으며 아동을 포함한 이용자의 개인정보를 의도적으로 수집하지 않습니다. 문의에 아동의 개인정보가 포함되었다고 생각되면 삭제를 요청해 주세요.

9. 변경 및 연락처

기능이나 데이터 처리 방식이 변경되면 이 페이지를 갱신합니다. 개인정보 관련 문의 및 삭제 요청: nicechann@gmail.com.
