StashDeck은 텍스트, 링크, 이미지, 파일과 코드 조각을 저장하고 검색·정리·재사용할 수 있는 macOS 클립보드 관리자입니다. 메뉴 막대에서 빠르게 열고, 필요한 항목을 다시 클립보드로 복사할 수 있습니다.

Key Features

복사 기록을 찾고 정리하는 더 빠른 방법

자주 쓰는 문구부터 이미지와 파일까지 한곳에서 관리하고, 필요한 순간에 검색하거나 컬렉션으로 정리해 다시 활용할 수 있습니다.

01

클립보드 히스토리

복사한 텍스트, 링크, 이미지, 파일과 코드 조각을 메뉴 막대에서 빠르게 확인합니다.

02

검색과 필터

키워드와 콘텐츠 유형으로 원하는 항목을 찾고 다시 클립보드에 복사합니다.

03

Pin · Tag · Collection

자주 사용하는 항목을 고정하고 태그와 컬렉션으로 목적에 맞게 정리합니다.

04

Deck Window

카드 기반의 넓은 화면에서 클립보드 기록을 탐색하고 세부 내용을 확인합니다.

05

Floating Deck

자주 사용하는 항목을 작은 플로팅 창에서 빠르게 불러와 반복 작업을 줄입니다.

06

백업과 선택형 iCloud 동기화

기록을 파일로 내보내거나, 사용자가 활성화한 경우 여러 Mac에서 iCloud로 동기화합니다.

로컬 저장을 기본으로 설계했습니다.

StashDeck 데이터는 기본적으로 사용자의 Mac에 저장됩니다. iCloud 동기화는 사용자가 직접 활성화한 경우에만 Apple CloudKit을 통해 동작합니다.
